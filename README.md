# Outside links (interim host)

Static landing pages for Outside invite links, served by GitHub Pages. The invite token is in the URL fragment (`/g/#<token>`), so it never reaches GitHub. The pages show no names and no photos.

- `/.well-known/assetlinks.json`: Android App Links for `com.outsideplans.app` (EAS staging keystore).
- `/f/`, `/g/`, `/p/`: friend, group and plan invite pages.

Interim only. Move to an owned domain before public launch.
